ФРЕЙМЛЁТ — ФАЙЛЫ НЕЙРОСЕТИ

Содержимое:
- dataset.py — создание синтетической обучающей выборки.
- features.py — извлечение числовых визуальных признаков из изображений.
- styles.py — описания и названия стилевых категорий.
- model.py — реализация архитектуры нейросети и вычислений.
- train.py — запуск обучения модели.
- export_to_site.py — экспорт обученной модели в HTML-сайт.
- weights.json — сохранённые веса модели.
- web_model.json — данные модели для использования на сайте.

Как связаны файлы:
dataset.py + features.py + styles.py -> train.py -> model.py/weights.json
-> web_model.json -> export_to_site.py -> freimelet/index.html

Важно:
Это исходные файлы AI-модуля проекта. Они показывают процесс создания,
обучения и переноса собственной модели в браузер. Внешний AI API
и отдельный Backend-сервер в этой реализации не используются.
